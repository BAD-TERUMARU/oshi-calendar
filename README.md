# 推し活カレンダー

OCHA NORMA、モーニング娘。'26、宮本佳林のライブ・イベント予定を、月間カレンダーで確認する非公式ファン向けWebアプリです。

2026年9月9日、イベント情報の更新をCloudflareへデプロイしました。公開URLのHTML・JavaScript・CSSが検証済みのローカルビルドと一致することを確認しています。

アプリの更新日とイベント情報の確認日は異なります。今回の掲載情報スナップショットは2026年9月9日時点です。

## できること

- 月間カレンダーでイベントを一覧表示
- 一覧表示と「行きたいだけ」表示
- 月曜始まりで予定を確認
- 日曜・祝日を赤字、土曜を青字で表示（2026〜2027年の祝日を同梱）
- アーティストごとの表示切り替え
- ライブ、フェス、BDイベント、リリース、舞台などの種別フィルター
- カレンダー内で主題が分かる短いイベント名を表示
- スマートフォンではカレンダー内の表示を地名（都道府県）優先に切り替え
- 日付を選択して会場、出演者、チケット状況、受付期間、公式リンクを確認
- 期間イベントの開催期間から参加日を個別選択
- 詳細画面でイベントを「行きたい」として端末に保存
- 昼公演・夜公演など、複数公演を公演単位で選択
- 未出力の選択を新規 iCalendar（`.ics`）として書き出し
- 直前に作成したICSファイルを再保存
- 内容が変わった予定を確認後に明示的に再出力
- 「行きたい」の選択解除と、出力履歴の消去を別操作で実行

## 現在のデータについて

このリポジトリには、2026年9月11日時点で公式公開ページを確認して整理した「公開情報スナップショット」を同梱しています。これは確認日時点の記録であり、最新情報や将来の変更を保証するものではありません。チケット状況や受付条件は変更される可能性があるため、利用時は各イベントの公式リンクを確認してください。

イベントは静的に同梱したデータだけを使用します。`/api/events`などへのAPI呼び出し、ページの自動巡回、自動解析、自動更新はアプリ自体には実装していません。公開データの確認・更新は、別途登録したCodexの定期タスク（毎日03:00 JST）から行います。データは`2026-09-11`時点の確認済みスナップショットで、最新情報や将来の変更を保証するものではありません。

2026〜2027年の祝日は、内閣府「[国民の祝日について](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)」を出典として同梱しています。

「行きたい」の選択状態、終了予定、出力履歴は利用中ブラウザのローカルストレージに保存され、サーバーには送信されません。公演IDはイベント内で`session-0`、`session-1`のように固定され、選択キーは`${event.id}::${session.id}`、ICSのUIDは`${event.id}-${session.id}`です。初回割当後に並べ替えや追加で再採番しない前提です。

新規ICS出力は未出力分が対象です。直前のファイルは再保存でき、内容変更分は確認後に明示的に再出力します。選択を解除しても出力履歴は残り、履歴消去は別操作です。ICSの重複を外部カレンダー側で防げる保証はなく、外部カレンダーの予定を削除・同期する機能もありません。

公演の開始時刻が確認できる場合は時刻付き、終了時刻も確認できる場合は開始〜終了の時間付きで書き出します。終了時刻が未確認の場合は、自分用の終了予定を入力できますが、公式の終演時刻とは区別して説明欄に記録します。公式情報から確認できた終了時刻だけに`end`を設定し、時間を推測して登録することはありません。

期間イベントは開催期間の全日程を自動的に参加日とはみなさず、詳細画面で参加日を個別に選択します。旧形式の「期間全体」選択が残っている場合も、全日程へ自動展開せず、公式情報と参加日を再確認してください。

## 公開データの取り扱い

掲載対象は、一般に閲覧できる公式ページのイベント名・開催日・会場・出演者・受付状況の要約・公式URLです。

- 会員限定ページの本文、画像、動画、ログインが必要な情報は掲載しません
- 公式ページの長文転載は行いません
- 公式運営と誤認されないよう、非公式ファン作成であることを明記します
- チケット受付状況は公式ページの最新表示と一致しない場合があるため、必ず公式ページを確認してください
- 公開情報であっても、各公式サイトの規約・権利条件に従い、公開可否に迷う情報は掲載しません

公開範囲に迷う情報は掲載せず、必要に応じて権利者への確認を行ってください。

## ライセンスと注意

このアプリは公式運営とは関係のないファン作成物です。アーティスト名、イベント名、ロゴ等の権利は各権利者に帰属します。スナップショットの日付表示や注意書きは、情報の鮮度と非公式性を示すためのものであり、転載・再配布の許諾を意味しません。イベント情報の利用・再配布については、各公式サイトの利用条件および関連する権利を確認してください。
