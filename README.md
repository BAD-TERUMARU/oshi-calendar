# 推し活カレンダー

OCHA NORMA、モーニング娘。'26、宮本佳林のライブ・イベント予定を、月間カレンダーで確認する非公式ファン向けWebアプリです。

## 公開URL

実際のアプリ: <https://oshi-calendar.badterumaru.workers.dev/>

Cloudflare Workers Static Assetsで公開しています。現時点では、2026年8月22日時点の確認済みスナップショットを配信しています。

## できること

- 月間カレンダーでイベントを一覧表示
- アーティストごとの表示切り替え
- ライブ、フェス、BDイベント、リリース、舞台などの種別フィルター
- カレンダー内で主題が分かる短いイベント名を表示
- 日付を選択して会場、出演者、チケット状況、受付期間、公式リンクを確認
- 期間イベントを開催期間中の日付に表示

## 現在のデータについて

このリポジトリには、2026年8月22日時点で公式公開ページを確認して整理した「公開情報スナップショット」を同梱しています。これは取得日時点の記録であり、最新情報や将来の変更を保証するものではありません。チケット状況や受付条件は変更される可能性があるため、利用時は各イベントの公式リンクを確認してください。

現時点では、ページの自動巡回・自動解析・日次自動更新は実装していません。Cloudflare上でも、データは同梱スナップショットを配信しています。将来の更新方式を検討するためのWorker/KV構成は、`cloudflare/` と `wrangler.example.jsonc` に記録しています。

## 公開データの取り扱い

掲載対象は、一般に閲覧できる公式ページのイベント名・開催日・会場・出演者・受付状況の要約・公式URLです。

- 会員限定ページの本文、画像、動画、ログインが必要な情報は掲載しません
- 公式ページの長文転載は行いません
- 公式運営と誤認されないよう、非公式ファン作成であることを明記します
- チケット受付状況は公式ページの最新表示と一致しない場合があるため、必ず公式ページを確認してください
- 公開情報であっても、各公式サイトの規約・権利条件に従い、公開可否に迷う情報は掲載しません

公開範囲に迷う情報は掲載せず、必要に応じて権利者への確認を行ってください。

## ライセンスと注意

このアプリは公式運営とは関係のないファン作成物です。アーティスト名、イベント名、ロゴ等の権利は各権利者に帰属します。スナップショットの日付表示や注意書きは、情報の鮮度と非公式性を示すためのものであり、転載・再配布の許諾を意味しません。イベント情報の利用・再配布については、各公式サイトの利用条件および関連する権利を確認してください。
