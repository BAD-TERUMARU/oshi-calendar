# 推し活カレンダー

OCHA NORMA、モーニング娘。'26、宮本佳林のライブ・イベント予定を、月間カレンダーで確認する非公式ファン向けWebアプリです。

## 公開URL

実際のアプリ: <https://oshi-calendar.badterumaru.workers.dev/>

Cloudflare Workers Static Assetsで公開しています。現時点では、2026年8月31日時点の確認済みスナップショットを配信しています。

## できること

- 月間カレンダーでイベントを一覧表示
- 月曜始まりで予定を確認
- 日曜・祝日を赤字、土曜を青字で表示
- アーティストごとの表示切り替え
- ライブ、フェス、BDイベント、リリース、舞台などの種別フィルター
- カレンダー内で主題が分かる短いイベント名を表示
- スマートフォンではカレンダー内の表示を地名（都道府県）優先に切り替え
- 日付を選択して会場、出演者、チケット状況、受付期間、公式リンクを確認
- 期間イベントを開催期間中の日付に表示
- 詳細画面でイベントを「行きたい」として端末に保存
- 昼公演・夜公演など、複数公演を公演単位で選択
- 選択したイベントを iCalendar（`.ics`）形式で書き出し
- 「リセット」で「行きたい」と書き出し履歴を一括消去

## 現在のデータについて

このリポジトリには、2026年8月31日時点で公式公開ページを確認して整理した「公開情報スナップショット」を同梱しています。これは確認日時点の記録であり、最新情報や将来の変更を保証するものではありません。チケット状況や受付条件は変更される可能性があるため、利用時は各イベントの公式リンクを確認してください。

現時点では、ページの自動巡回・自動解析・日次自動更新は実装していません。Cloudflare上でも、データは同梱スナップショットを配信しています。将来の更新方式を検討するためのWorker/KV構成は、`cloudflare/` と `wrangler.example.jsonc` に記録しています。

「行きたい」の選択状態と書き出し済みの記録は、利用中のブラウザのローカルストレージに保存され、サーバーには送信されません。書き出した `.ics` ファイルは、Google カレンダー、Apple カレンダー、Outlookなどのカレンダーアプリに追加できます。「カレンダーへ追加」は未書き出しの予定だけを書き出すため、同じ選択内容を続けて登録する操作を抑止します。さらに、イベント・公演ごとに固定IDを付けています。

公演の開始時刻が確認できる場合は時刻付き、終了時刻も確認できる場合は開始〜終了の時間付きで書き出します。終了時刻が確認できない場合は開始時刻のみ、時刻自体がない予定は終日として扱い、開場・開演などの情報は説明欄に残します。公式情報から終了時刻を確認できた予定だけに `end` を設定し、時間を推測して登録することはありません。

## 公開データの取り扱い

掲載対象は、一般に閲覧できる公式ページのイベント名・開催日・会場・出演者・受付状況の要約・公式URLです。

- 会員限定ページの本文、画像、動画、ログインが必要な情報は掲載しません
- 公式ページの長文転載は行いません
- 公式運営と誤認されないよう、非公式ファン作成であることを明記します
- チケット受付状況は公式ページの最新表示と一致しない場合があるため、必ず公式ページを確認してください
- 公開情報であっても、各公式サイトの規約・権利条件に従い、公開可否に迷う情報は掲載しません

公開範囲に迷う情報は掲載せず、必要に応じて権利者への確認を行ってください。

## ライセンスと注意

このアプリは公式運営とは関係のないファン作成物です。アーティスト名、イベント名、ロゴ等の権利は各権利者に帰属します。スナップショットの日付表示や注意書きは、情報の鮮度と非公式性を示すためのものであり、転載・再配布の許諾を意味しません。イベント情報の利用・再配布については、各公式サイトの利用条件および関連する権利を確認してください。
