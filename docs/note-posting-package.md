## Note上での整形

- Markdownの`#`と`##`を貼り付けた後、タイトルはタイトル欄へ、各章はNoteの見出しスタイルへ変換する
- 本文中の公式ページ・アプリ・GitHubのリンクがリンクとして認識されていることを確認する
- 画像はカレンダー画像、詳細画像の順に配置し、キャプションを付ける
- 目次は今回必須にしない。追加する場合は、Noteの本文挿入メニューからネイティブの目次を1つだけ挿入する

## 投稿前の確認項目

- [ ] 記事タイトルと本文の9/9・58件が、GitHubと公開アプリに一致している
- [ ] 前回記事リンクの公開状態を確認した
- [ ] 画像2枚が意図した位置にあり、キャプションが付いている
- [ ] 「さわやか五郎さんのBDイベント」を関連イベントとして掲載した理由が残っている
- [ ] 非公式アプリ、スナップショット、最新情報は公式確認が必要という注意書きがある
- [ ] 公開範囲、価格、コメント、マガジン、AI学習参加、予約投稿の設定を確認した
- [ ] 投稿直前に公開してよいことを明示的に承認した
