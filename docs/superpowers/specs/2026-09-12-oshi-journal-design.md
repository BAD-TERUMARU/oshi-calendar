# 現場記録・振り返り・生涯セトリ

## 目的と承認
ユーザーは2026-09-12に、既存アプリ全面レビューと「現場管理＋推し活ダッシュボード＋生涯セトリ」を含む7件について「全部ゴールまで自走して」と承認した。既存カレンダーの表示、公式情報、行きたい、ICS出力を保ちながら個人の記録を追加する。

## 選択した設計
既存React/TypeScript/Vite構成を拡張する。全面作り直しや新しい有料サービスは不要。既存の端末内保存に合わせ、個人記録は新しいキーに分離する。カレンダーの公式情報と個人の体験記録を混同しない。

1. 選択した公演を公演単位で現場記録へ追加。公演IDで重複登録を防ぎ、イベント名・日付・会場は登録時点の値を保持する。過去の現場は手入力できる。
2. 記録には参加予定/参加済み/見送り、アーティスト、会場、日付、公演名、感想、評価、チケット・交通・その他の金額、1行1曲のセトリを保存。年月・アーティスト・状態で絞り込み、編集・削除する。
3. 振り返りは参加済みだけを集計し、参加公演数、会場数、登録支出、曲数、月別公演数、アーティスト別公演数を表示する。金額は登録済みの合計であることを明記する。
4. 生涯セトリは参加済み記録から、曲別の聴いた公演数・初回・最終回・該当現場を表示する。同じ公演内の同じ曲は公演数として一回。実在する曲・セトリを自動で捏造しない。
5. バージョン付きJSONの書き出し・取り込みを提供。取り込みは厳密に検証して全件成功時のみ追加し、既存IDは上書きせずスキップ。破損保存データを自動で空配列に置換しない。保存失敗はユーザーに知らせ、画面上の編集とバックアップ出力を維持する。

## 完了条件
既存テストが通る。新規の重複防止、日付・金額検証、参加済み集計、セトリ集計、JSON往復・不正データ保護を試験する。ビルドが通り、375pxと1280pxで主要フローを実操作できる。レビュー指摘の妥当な不具合を修正する。GitHub上にレビュー可能な差分と説明を保存する。Cloudflare本番への到達状況は別途確認し、未反映なら明示する。
